## ✨ Features
✅ Bem vindos! Este é um projeto com o objetivo de criar uma aplicação em React com temática de treinamento, fornecendo informações, exercícios, alimentação, anotações, músicas, videos, timer em tempo real, além de ler e criar novos usuários, entre outras funcionalidades de forma organizada para maximizar a performance dos treinos. Esta é uma aplicação teste que poderá ser utilizada por praticantes de atividade física durante suas rotinas de treino, alimentação e descanso. Minha gratidão a Deus pela finalização do projeto.

<!-- Possui funcionalidades de atualizar e remover usuários e exercícios de forma funcional e dinâmica. (Posteriormente) -->

✅ Welcome! This project aims to build a React application focused on training, providing information on exercises, nutrition, notes, music, videos, a real-time timer, as well as reading and creating new users, among other features, all organized to maximize workout performance. This is a test application intended for use by fitness practitioners during their training, nutrition, and rest routines. My gratitude to God for the completion of this project.
